\section{Introduction \& Project Idea}

\subsection{The Problem: The Friction of Group Planning}
Organizing activities for 3 to 10+ people (whether an international vacation, weekend road trip, dining out, or casual social hangout) consistently suffers from severe real-world bottlenecks:
\begin{itemize}
    \item \textbf{Exhausting \& Time-Consuming Manual Research:} Planners must browse dozens of disparate platforms (blogs, Google Maps, review sites, booking portals, flight aggregators) to compile opening hours, ticket pricing, and transit routes---wasting days or even weeks of tedious manual effort.
    \item \textbf{High Friction in Satisfying Everyone's Tastes:} Manually modifying an itinerary whenever a member expresses dissatisfaction is agonizingly slow and complex; adjusting a single stop triggers a chain reaction across transit routes, timing, and group budget, making it nearly impossible to manually tailor a plan that pleases everyone.
    \item \textbf{Fragmented \& Messy Group Chats:} Travel ideas, photo links, and flight screenshots get buried under hundreds of unstructured messages on Zalo, Messenger, or WhatsApp, causing critical information to be lost.
    \item \textbf{Organizer Burnout \& Single Point of Failure:} Typically, a single organizer bears the entire cognitive and emotional load of researching, polling members, and making compromises, only to face complaints if the group is unsatisfied.
    \item \textbf{Complex Schedule Overlaps ($\pm\delta$ Tolerance):} Member A is free from the 10th to the 20th ($\pm 1$ day), while Member B is available from the 15th to the 25th ($\pm 2$ days). Manually determining the optimal intersecting window that maximizes attendance is a painful combinatorial puzzle.
    \item \textbf{Conflicting Preferences \& Decision Deadlocks:} When half the group desires active mountain trekking while the other half seeks relaxed beach resorts, the group falls into decision paralysis, often leading to canceled plans.
    \item \textbf{Accommodation \& Room Booking Bottlenecks:} Finding and coordinating suitable room configurations (bed layouts, group room blocks, cancelation policies) for large parties across multiple booking sites is cumbersome and prone to booking errors.
    \item \textbf{Group Dining Logistics \& Split Debt Friction:} Finding venues that handle large-party seating while catering to diverse dietary constraints (allergens, vegetarian, halal) is difficult, and manually calculating post-trip shared debts creates social awkwardness.
\end{itemize}

\subsection{The Solution: A Synchronized Group Room with Human-in-the-Loop AI}
\textbf{TripMate AI} transforms group planning into a streamlined, consensus-driven workflow in \textbf{under 15 minutes}:
\begin{enumerate}
    \item \textbf{Collaborative Room Chat (Freeform Brainstorming):} All members join a shared room to discuss rough travel wishes, general preferences (e.g., ''a warm getaway in autumn'' without requiring strict dates upfront), and personal profile constraints.
    \item \textbf{One-Click Handoff \& Proactive AI Clarification (Q\&A Loop):} The organizer submits the room's collective discussion to the \textbf{Unified Trip Intelligence Agent}. If any critical parameters are missing or ambiguous (e.g., date flexibility, passport status, specific dietary details, budget limits), the Agent proactively posts targeted follow-up questions directly in the chat room to gather full details from members.
    \item \textbf{Autonomous Multi-Source Research:} Once fully informed, the Agent resolves schedule overlaps, checks live places/menus, evaluates visa/legal guidelines, and constructs an optimized itinerary.
    \item \textbf{Granular Leg-by-Leg Voting:} The plan is presented with \textbf{stop-by-stop interactive voting} (UP/DOWN/Alternative Proposal). If a specific stop is rejected, the Agent immediately swaps it without breaking the rest of the schedule.
    \item \textbf{Group Final Consensus \& Debt Settlement:} The entire group conducts a final vote to democratically lock the finalized itinerary once consensus is reached, after which automated algorithms simplify all group debts into minimum peer-to-peer transfers.
\end{enumerate}

\section{Platform Features \& Core Functionalities}

TripMate AI delivers a comprehensive suite of web features tailored specifically for group collaboration:

\subsection{1. Collaborative Group Room \& Profile Onboarding}
\begin{itemize}
    \item \textbf{Live Gathering Room:} A shared room where members join via invite link or email, chat freely, brainstorm destinations, and input individual profiles (dietary constraints, budgets, rough availability) without needing locked dates upfront.
    \item \textbf{Interactive Agent Q\&A Intake:} When submitted, the Agent actively prompts the room with quick interactive clarifying questions to fill in any missing data before generating plans.
    \item \textbf{6 Tailored Event Types:} Built-in templates for Multi-Day Travel (\texttt{TRAVEL}), Dining Out (\texttt{DINING}), Cafe Hangouts (\texttt{HANGOUT}), Entertainment \& Arcade (\texttt{ENTERTAINMENT}), Cultural Sightseeing (\texttt{SIGHTSEEING}), and Custom Events (\texttt{CUSTOM}).
    \item \textbf{Role-Based Permissions (RBAC):} Distinct permissions for \textbf{Host/Organizer} (creates event, invites members), \textbf{Member} (chats, inputs preferences, votes on stops, and participates in final plan locking vote), and \textbf{Viewer} (read-only access).
\end{itemize}

\subsection{2. AI-Powered Planning \& Research Hub}
\begin{itemize}
    \item \textbf{1-Click AI Generation:} Instant proposal generation from room chat context using DeepSeek-V4.
    \item \textbf{Destination Profiling:} Deep introductions to destinations (e.g., exploring Da Nang's iconic bridges, Ba Na Hills, cultural heritage, and local specialties).
    \item \textbf{Live Inventory \& Price Lookup:} Real-time flight search, hotel comparisons, attraction tickets, and tour packages via Amadeus, Booking.com, and Klook APIs.
    \item \textbf{Group Dining Planner:} Filters restaurants by party size capacity, accommodates allergens/dietary restrictions (Halal, vegan), and suggests family-style banquet menus.
    \item \textbf{International Visa \& Legal Briefing:} Automatic passport validity check ($\ge 6$ months), e-Visa guidance, reputable visa agency recommendations, local cultural etiquette, and scam advisories.
\end{itemize}

\subsection{3. Democratic Voting \& Plan Customization}
\begin{itemize}
    \item \textbf{Granular Leg-by-Leg Voting:} Independent voting cards on every stop (Hotel, Lunch, Activity) with instant 1-click alternative proposals.
    \item \textbf{Adaptive Conflict Resolver \& Mediation:} When automated algorithms cannot find an obvious overlap (e.g., zero intersecting dates, diametric budget or travel style conflicts), the Agent engages in targeted, individual-specific Q\&A to negotiate trade-offs and uncover viable middle-ground directions.
    \item \textbf{Streaming AI Chat Assistant:} Real-time conversation with the AI via WebSockets/SSE to modify itinerary cards on the fly.
    \item \textbf{Manual Drag-and-Drop Plan Builder:} Autocomplete place search via Google Places, auto-calculating route travel times and hotel rates for manual planners.
\end{itemize}

\subsection{4. Interactive Map \& Smart Utilities}
\begin{itemize}
    \item \textbf{Interactive Mapview (Mapbox GL JS):} Visualizes timeline stops, routing paths, transit durations, and categorized map pins.
    \item \textbf{Weather-Aware Packing Checklist:} Auto-generates tailored packing items based on OpenWeatherMap destination forecasts and event types.
    \item \textbf{1-Click PDF Export (WeasyPrint):} Generates a polished PDF booklet containing full daily timelines, map snapshots, hotel reservations, and emergency contacts.
    \item \textbf{Bilingual Interface (i18n):} Seamless instant switching between Vietnamese and English.
\end{itemize}

\subsection{5. Shared Expense Splitting \& Debt Settlement}
\begin{itemize}
    \item \textbf{Expense Tracking:} Records pool pre-funding (\texttt{ADVANCE}) and real expenses (\texttt{PAYMENT}).
    \item \textbf{Flexible Split Types:} Supports equal split (\texttt{EQUAL}), exact amounts (\texttt{EXACT}), or percentages (\texttt{PERCENTAGE}).
    \item \textbf{Automated Debt Settlement:} A greedy matching algorithm computes net balances and outputs the minimum number of peer-to-peer bank transfers needed.
\end{itemize}

\begin{enumerate}[label=\textbf{Step \arabic*:}]
    \item \textbf{Ingestion, Context Extraction \& Proactive Q\&A Loop (DeepSeek-V4 Flash):} The Agent parses the chat room stream to extract attendee profiles, general wishes, budget bounds, and date windows $[S_i, E_i] \pm \delta_i$. If essential constraints are missing or ambiguous (such as unstated date ranges, passport/visa status, or dietary specifics), the Agent proactively triggers interactive clarification prompts in the room chat to gather complete information before advancing to heavy computation.
    \item \textbf{Schedule Optimization \& Individualized Date Mediation (DeepSeek-V4 Pro):} Evaluates overlapping availability intervals to determine optimal trip dates:
    \begin{equation}
        \max_{T_{\text{start}}, T_{\text{end}}} \sum_{i=1}^{N} w_i \cdot \mathbb{I}\left( [T_{\text{start}}, T_{\text{end}}] \subseteq [S_i - \delta_i, E_i + \delta_i] \right)
    \end{equation}
    \textit{Deadlock Mediation Fallback:} If no overlapping window satisfies the group (zero intersection), the Agent isolates the blocking constraints and initiates \textbf{Targeted Individual Inquiries} (e.g., asking Member A if shifting departures by half a day is feasible, or proposing staggered attendance where Member C joins for a partial segment).
    \item \textbf{Parallel Multi-API Tool Calling:}
    \begin{itemize}
        \item \textit{Place Intelligence:} Queries Google Places/Mapbox for destination profiling, geocoordinates, and transit durations.
        \item \textit{Live Pricing:} Queries Amadeus, Booking.com, and Klook for flights, hotel room blocks, and entry tickets.
        \item \textit{Cross-Border Intelligence:} Checks passport validity ($\ge 6$ months), e-Visa portals, visa agencies, local laws, and cultural taboos.
        \item \textit{Climate Intelligence:} Fetches OpenWeatherMap forecasts to adapt indoor/outdoor activity allocations.
    \end{itemize}
    \item \textbf{Preference Reconciliation \& Adaptive Idea Negotiation (DeepSeek-V4 Pro):}
    \begin{itemize}
        \item \textit{Individualized Negotiation on Ideological Deadlocks:} If tastes are sharply polarized (e.g., Beach vs. Mountain, High-Pace Nightlife vs. Quiet Nature), the Agent queries conflicting members individually to diagnose underlying motivations (e.g., discovering someone avoids mountains due to trekking fatigue) and proposes creative compromises (e.g., luxury mountain cable-car resort with spa + nearby coast).
        \item \textit{Group Dining \& Allergen Management:} Identifies venues with large-party seating and crafts family-style banquet menus compliant with all dietary needs (Halal, vegan, allergen-free).
    \end{itemize}
    \item \textbf{Schema Validation \& Streaming Delivery:} Formats output into strict \textbf{Pydantic v2} JSON schemas and streams real-time Proposal Cards to the frontend via WebSockets / SSE.
    \item \textbf{Granular Voting Loop \& Localized Repair:} If members downvote a specific leg (e.g., Day 2 Lunch), the Agent immediately invokes a localized tool call to fetch 3 alternative options without recalculating or disrupting the overall itinerary. Once consensus is reached, the plan is locked democratically.
\end{enumerate}

\subsection{Deep Reasoning: Adaptive Individualized Mediation \& Deadlock Resolution}
A core innovation of TripMate AI is its ability to handle scenarios where standard mathematical optimization fails to find an obvious solution:
\begin{itemize}
    \item \textbf{Zero-Intersection Date Deadlocks:} When members have rigid, non-overlapping date availability, the Agent does not output an error. Instead, DeepSeek-V4 Pro reasons over the constraint matrix, detects the specific bottleneck individuals, and generates personalized compromise questions directly in the group chat (e.g., \textit{''@Alex, if we shift the departure to Friday evening instead of Thursday, could you attend?''} or \textit{''@Sarah, would joining the group for the first 3 days work for your schedule?''}).
    \item \textbf{Deep Motivation Probing for Idea Conflicts:} When group members clash over destinations or activities (e.g., Budget Backpacker vs. Luxury Comfort, Mountain vs. Ocean), the Agent conducts targeted inquiries to uncover root preferences and synthesizes hybrid options that address each member's core desires without alienating anyone.
    \item \textbf{Continuous Consensus Convergence:} Through multi-turn empathetic mediation, the Agent iteratively refines proposals until the entire group converges on a mutually satisfying direction.
\end{itemize}

\section{Backend Architecture \& Data Flow}

\subsection{Tech Stack \& Monorepo Structure}
\begin{itemize}
    \item \textbf{Runtime \& Framework:} Python 3.11+ with \textbf{FastAPI} (high-speed ASGI, native async/await, automated OpenAPI documentation at \texttt{/docs}).
    \item \textbf{Database \& ORM:} \textbf{PostgreSQL} paired with \textbf{SQLAlchemy 2.0 (Async)} and \textbf{Alembic} migrations for type-safe database versioning.
    \item \textbf{Caching \& Message Broker:} \textbf{Redis} for caching external API lookups (TTL 6--24h), rate-limiting, and WebSocket Pub/Sub synchronization.
    \item \textbf{Background Tasks \& Export:} FastAPI BackgroundTasks / Celery for async PDF generation (\textbf{WeasyPrint}) and email delivery (aiosmtplib).
\end{itemize}

\subsection{Optimal 3-Table Financial Settlement Engine}
Rather than maintaining complex accounting ledgers, the backend computes debts using 3 relational tables (\texttt{expenses}, \texttt{expense\_splits}, \texttt{settlements}). A greedy matching algorithm computes net balances ($\text{Net}_u = \sum \text{Paid}_u - \sum \text{Owed}_u$) and produces the minimum number of peer-to-peer bank transfers.
